# Assist web icons

The icons in this directory are vendored unchanged from `@hugeicons/static`
version `0.1.5` (Hugeicons Stroke Rounded).

- Source: https://github.com/hugeicons/hugeicons-static
- License: MIT

`menu-01.svg` and `cancel-01.svg` provide the mobile navigation controls.
`refresh.svg` provides the Fun mode Restart control, matching the Mac app's
bundled Hugeicons refresh icon.
